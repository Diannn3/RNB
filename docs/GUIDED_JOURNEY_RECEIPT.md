# Guided journey implementation receipt — October 9, 2026

## Delivered behavior

PDF upload opens a guided conversation. The conversation collects missing details, presents contextual alternatives, supports source navigation and permits PDF questions. Verification provides editable answers and a working PDF preview, with explicit human approval. Export is a dedicated page whose preview and download use the same generated bytes.

Real files use a truthful manual interview while the backend is disconnected. The fictional sample demonstrates cited PDF questions deterministically. The typed optional `turn` adapter supports cancellation, expected revisions, source validation and explicit acceptance of proposals; no HTTP endpoints are invented.

Navigation retains the session and transcript. Edits invalidate approval; stale replies and generated previews cannot apply to newer state. Export omits unreviewed entries only after an explicit incomplete-draft choice. Project schema version 2 saves conversation and stage along with answers and hashes; version 1 remains supported. Resuming an export stage returns to verification rather than treating an old artifact as current.
